Stage 02

Implementation

The agent is a store of what was seen to follow what, plus four operations on it: observe, predict, be curious, and plan. This page describes the version used in stages 3 and 4.

Facts

Everything the agent knows is written as named values, called facts. A situation is a set of facts, such as action = right, x = 4, y = 4.

The knowledge base

The knowledge base is a flat store. Each entry has a set of input facts and the outcomes that were seen to follow them, each with a count. Nothing is nested.

InputsOutcomeSeen
action = rightdx = +1, dy = 07
action = rightdx = 0, dy = 01
action = right, x = 4, y = 4new_state = (5, 4)1

An entry with fewer inputs applies more widely. That is the hierarchy: it is not a separate structure, only the relation between entries with fewer and more inputs.

Observing

One observation is a state, an action and the state that followed. The agent stores it at two levels of generality.

  • General: the action alone, followed by the change it caused.
  • Specific: the whole state and the action, followed by the new state and by the change.

Observing is the same whether the agent made the move or watched it happen. This is what lets one agent learn by watching and by acting.

Querying

A query asks for one fact, given what is known. An entry applies when all of its inputs are among the known facts. Of the entries that apply, the one with the most inputs wins, and a tie goes to the outcome seen most often.

Predicting

  1. If this exact state and action has been seen, predict the state that followed. One sighting is enough.
  2. Otherwise take the change the action most often causes and apply it to the current state.

The second step is why the agent can predict what happens in places it has never been.

Curiosity

  • Zero if this exact state and action has been seen.
  • Otherwise one divided by the number of times the action has been seen.
  • Zero once the action has been seen five times.

While exploring, the agent takes the action it is most curious about. When nothing nearby is interesting it moves at random. It stops when every action has been seen five times.

Planning

To reach a goal the agent searches breadth-first through predicted states, calling predict on the result of the previous prediction. If the search gives up, it falls back to stepping toward the goal greedily.

Surprise

While following a plan, the agent compares each result with its prediction. When they differ, the observation it stores becomes a specific entry that overrides the general rule there, and the agent plans again from where it is.

What the world provides

The world provides the list of actions, the current state, and names for the parts of a state. The agent brings a representation: how a state becomes facts, how the difference between two states is measured, and how far apart two states are. In stages 3 and 4 that representation is raw coordinates. This is the built-in part, and stage 5 is about how much of it should stay built in.
