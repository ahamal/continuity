The third agent

This is the third build. It writes the same rows as the second agent, and answers with the most specific row that applies.

How it works

  • Writes. The same rows as the second agent: one for every combination of the facts in a move. The one difference is the count. Each different move is counted once, so repeating the same bump does not make a row look stronger.
  • Answers. With the most specific row that applies. At the left edge both "left" and "left, x = 0" apply. The second has more facts, so it answers. When two rows are equally specific and disagree, the one with the better record answers. A row's record is the times it held, divided by the times it was seen plus one, so a row seen once counts as a guess.
  • Explores. It goes to the move it is least sure about and tries it. It also plans through rows it has seen fewer than five times, so that a guess gets tested.

Try it

Press Explore. The knowledge base on the right shows each general row, with the more specific rows indented under it. Click a row to see the cells it answers for. Click a cell to see which rows answer there.

The first agent needed 388.

Entities should not be multiplied beyond necessity.

Occam's razor

Nobody told the agent that the move is the fact that matters most. The rows about a move ended up on top because they need the fewest specific rows beneath them:

RowMoves it answers for itselfSpecific rows beneath it
Up, down85 of 852 each: an edge, and one side of the wall
Left, right82 of 825 each: an edge, and four sides of the wall
x = 0, and every other row about a place12 of 12 or fewer19 or more each

What is missing

The agent found the wall, but only as separate cases. "Something is in the way" cannot be said with x and y, so the wall is ten unrelated rows. Nothing learned at one side of it helps at the next side, or at another wall.

Writing every combination also does not scale. Each fact added to the state multiplies the rows for one move by four: 127 with x and y, and 32,767 if we add what is to the left, right, above and below.

And we still hand it a few things: the facts themselves (that a place is an x and a y), that the question to ask is what will change, the "plus one" in a row's record, and how long it explores, which is 100 steps.
