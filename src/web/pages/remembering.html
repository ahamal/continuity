The first agent

This is the first build of the engine from the last page. It keeps two levels of assumption: what a move does in general, and what it did at one exact place.

How it works

  • Writes. Two rows for every move it sees: one for the move alone, "going right adds one to x", and one for the move at that exact place, "going right from (9, 4) changes nothing".
  • Answers. With the row for the exact place if it has one, and otherwise with the row for the move alone.
  • Explores. It makes the move it is most curious about, and stops once it has seen each move five times.

Try it

Press Explore, then click a cell beyond the wall and send it there. The knowledge base on the right shows the rows as they are written. A bar on the grid marks a move it has learned does nothing, and each bar took its own bump.

Results

We ran the agent 500 times in each world. In each run it explores first and is then sent to a goal.

WorldRuns that reached the goal
1D line500 of 500
2D grid500 of 500
2D grid with a wall367 of 500

On the line and the open grid it works every time. A few moves are enough for it to know what each move does, and the general rows then carry it to places it has never been.

What is missing

The wall is where it struggles, and the reason is the two levels. The agent can say "going right adds one to x" for the whole grid, and it can say "going right from (4, 4) changes nothing" for one cell. It has no way to say anything in between, such as "going right at x = 9 changes nothing", which would cover the whole right edge in one row.

So it learns the edge and the wall one cell at a time. Bumping the right edge at (9, 4) tells it nothing about (9, 5). Knowing the whole world with a wall this way takes 388 rows, nearly one for every move there is. When it is sent to a goal behind the wall, it plans straight through, bumps, writes one row and plans again, and in 133 of the 500 runs it runs out of tries.

Its curiosity is also about moves and says nothing about places. Once it has seen each move five times it is confident, which takes about twenty moves near where it starts. So exploring never reaches the wall, and it only finds the wall when a goal sends it there.
