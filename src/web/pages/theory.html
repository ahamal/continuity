Stage 01

Background theory

The aim is one agent. It is not a language model and it is not trained in advance. It starts with no knowledge of a world, learns how that world works by watching it or by trying things, and then acts in it. The same agent should do this for a line, a grid and many board games, and what it has learned should be readable.

Identity

An identity is a label the observer assigns to part of the world: "this is a thing". The world does not hand it over. Physics has atoms, and the observer decides there is a ship.

The Ship of Theseus shows this. Replace every plank and ask whether it is the same ship. The question has no answer in the planks, because "ship" was never in them. The paradox is not a problem to solve. It shows how cognition works.

Continuity

A continuity is a learned pattern that links states across time: how an identified thing changes from one moment to the next, often in response to an action. Each continuity has two properties.

  • Generality: how widely it applies.
  • Strength: how often it has been observed.

Identity and continuity cannot be separated

Continuity is what tells you whether this is the same item as before. Identity is what a continuity is learned about. Each is needed to derive the other, so they are treated as one mechanism, not two.

Hierarchy

Knowledge is organised from general to specific. When both apply, the specific one overrides the general one.

Generality runs along more than one direction. A rule can be general or specific about when it applies, and also about who it applies to: every thing, every thing of one kind, or one individual. If all pawns move the same way, "pawn" is a level in the hierarchy. A kind is the set of things that one continuity covers.

Curiosity

Curiosity is the inverse of how complete the agent's knowledge is. It drives the agent to try what it knows least about, it falls as observations accumulate, and below a threshold the agent is confident and stops exploring. When the agent has nothing to watch, curiosity is how it comes to understand a world.

Surprise

A surprise is a prediction that turns out wrong. The agent responds by learning a more specific rule for that case and planning again. This is how it adapts to walls, edges and exceptions.

Reasoning as stacked continuity

Reasoning needs continuity. Hold identities stable, chain continuities one after another, and let each step build on the one before. Planning a route is the first example: the agent reaches a conclusion about a place it has never been.

Uncertainty is incomplete state

In a deterministic world, if the same situation leads to different outcomes, some part of the state is missing from the agent's representation. Uncertainty is therefore a signal to represent more, not a property of the world.

Learning while operating

The agent has no separate training phase. Every observation changes what it knows, including observations made while it is working toward a goal.

What is built in

Some structure has to exist before any learning can happen. The framework is itself such structure, and so are a few primitives: distance, direction, cycles, containment and causation. Stating them openly is part of the theory.
