The fourth agent

This is the fourth build. It keeps the third agent's rows and changes which row answers. It starts from the general row, and a more specific row answers only if it has held every time.

How it works

Compared with the third agent, everything in blue is different:

  • Writes. The same rows as the third agent, counted the same way.
  • Answers. For a move it has made, with what that move did. Otherwise it starts from the general row: of the rows with one fact, the one that has been right about the most moves. A more specific row beneath it answers instead only if it has held every time it was seen. A row that has failed even once is not followed.
  • Explores. The same way as the third agent.

This is the difference between the edge and a guess. "Going right at x = 9 changes nothing" has held every single time, so it answers for the whole edge. "Going right at x = 4 changes nothing" came from three bumps into the wall. Once the agent got past at x = 4 somewhere else, that row had held 3 times out of 5. The third agent went on following it, over "going right adds one to x" at 23 out of 26, because it is the more specific row. The fourth agent drops it. The bumps it saw at the wall still stand, each as its own row, and everywhere else in the column the general row answers.

Try it

Press Explore. Then send it to a cell beyond the wall and back, a few times, and watch which way it goes round. The knowledge base on the right shows each general row, with the rows that have always held indented under it.

Results

The earlier test asks only whether a goal is reached, and this agent reaches it in all three worlds, as the third one does. To see the difference we need a test of the routes. Each agent explores, then makes ten trips to cells picked at random, one after another. That is 500 trips over 50 runs, each compared with the shortest route there is.

On the grid with a wallTrips that reached the goalMoves, against the shortest routes
First agent482 of 5007% more
Second agent265 of 50014% more
Third agent494 of 50015% more
Fourth agent500 of 5008% more

The fourth agent is the only one that reaches every trip. Its routes are about half as wasteful as the third agent's. The moves are counted over the trips that were reached, so the first agent's 7% leaves out the 18 trips it gave up on.

On the open grid, with no wall, it takes the shortest route on all 500 trips.

What is missing

Some of the 8% that is left is bumps. The agent still learns the wall one cell at a time: each cell beside it costs one bump before the agent knows it is blocked. That is the same limit as before. "Something is in the way" cannot be said with x and y.

"Held every time" is also a strict test. It suits a world with no chance in it. In a world where the same move can turn out differently, nothing would hold every time, and this agent would follow only its general rows.

Everything else we hand it is unchanged from the third agent: the facts themselves, that the question is what will change, and writing every combination, which does not scale.
